# Designing Meaning: A Mini Textbook on Persuasion, Archetypes, and Visual Language

This mini textbook introduces a practical way to understand design as a system for shaping attention, meaning, and action. Each chapter builds on the idea that design is never just decoration. It is a way of making claims about value, identity, and trust.

The chapters in this book connect persuasion, brand meaning, visual language, and AI-assisted creative work into one usable framework. Read them in order, or return to them when you need a quick reminder of how design choices influence audience experience.
